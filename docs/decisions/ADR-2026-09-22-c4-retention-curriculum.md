# C4 retention and continuous-distribution curriculum experiment

Status: implementation and bounded experiment authorized by the user on 2026-09-22.

## Context and evidence

The original full-C3 model_175 is research initialization, not promoted authority.
The previous 201-iteration C4 run completed despite stale September 10 handoff text.
Development tracking declined from 96/96 at iteration 25 to 5/96 at 50 and 0/96
at 75--200. Survival alone did not detect the loss. Same-observation channel
replacement implicates tail coordination but does not identify a PPO mechanism.

## Decision and boundaries

First establish retention on the existing mild no-wind C4 distribution. Keep
CPU-native physics, actions, observations, rewards, preview, old samplers, and
six-group PPO weights unchanged. The user-approved plan is staged: expansion,
multi-seed confirmation and wind depend on a passing retention result.
Do not open the sealed holdout during method selection.

Implement explicit opt-in training variants A/B/C/D: fixed/adaptive C4 sampling
crossed with absent/present frozen successful-behavior memory. Defaults remain
the original training route. The adaptive sampler partitions heading amplitude
(.005--.009 rad/m) and slope amplitude (2--4 degrees) into four equal-area bins;
other recipe bounds and geometric screens stay unchanged. Rejection occurs
inside the selected bin, never replacing it with an easier bin. These are
candidate ranges, not dynamically certified limits.

This is a transparent discretized adaptation of self-paced distribution curricula
and absolute-learning-progress ideas, not an implementation of SPDL or ALP-GMM.
Maintain nonzero sampling of every bin; update only using completed training
episodes, with minimum counts and bounded distribution changes. Serialize the
teacher statistics and private RNG independently from the policy RNG.

Behavior memory is generated by deterministic frozen source inference on NEW
training samples, never from development/holdout traces. Retain finite surviving
episodes with acceptable tracking; balance the six task families. Freeze the
result before comparisons and record source/config hashes and collection cost.
Use fresh transitions for PPO and a separate mean-action imitation loss on
memory observations through the existing auxiliary-loss extension point. This
first experiment does not constrain the critic or exploration standard deviation
and does not claim to reproduce CLEAR's off-policy value/policy learning.

## Experiment and validation

Four arms use the same source weights, fresh optimizer, seed 0, 256 environments,
48 steps, 16 minibatches, 101 iterations and 25-iteration save interval. Memory
coefficient is predeclared as 1.0 on normalized mean-action MSE (not a proven
optimal value). Record all settings in each contract. Training samples and
memory-collection overhead are reported separately. Diagnose task actor gradients,
post-update KL/actions and critic residuals without modifying the update.

Run pure tests, native mixed-task smoke, and fresh-process resume before formal
training. Evaluate 50/75/100 in fresh processes on development plus all five old
suites. No promotion from a single checkpoint; require the existing sample cadence
and adjacent all-suite passing pair. Historical results remain immutable.
Nonfinite state, missing evidence, incompatible resume or incomplete memory fails
closed. A failed scientific gate is recorded, not repaired by relaxing limits.

## Alternatives and consequences

Merely changing task reset fractions is insufficient because the current adapter
rescales advantages to fixed task weights. Therefore adapt within C4 first.
PCGrad/multiple critics require gradient/value evidence; expert-to-student
distillation remains a fallback. Memory increases compute and can restrict new
learning. The current pilot tests stability, not wider-envelope learning.

## Reconsideration

After complete A--D evidence, proceed to broader curves only if retention passes.
If all variants fail, inspect reward alignment, gradients and critic errors before
any new bounded experiment. No automatic indefinite training or wind expansion.
