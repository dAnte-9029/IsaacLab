# Single-Teacher Path Mission Logging Check

Date: 2026-04-11

Scope:

- Non-RL DeLaurier path mission.
- `level_straight`, 180 m, 5000 steps, no path warmup.
- Purpose was to remove the logging-side direct call to the stateful teacher controller, then re-check the long-straight height response and plot readability.

## What Changed

- `fly_path_mission.py` no longer calls `_compute_teacher_actions()` directly in the rollout loop.
- The env computes the PX4-like teacher once inside `env.step()`, as part of normal teacher-guidance execution.
- `straight_flight_env.py` now caches the last teacher action/diag and the last executed actuator command before reset can overwrite `_act_cmd/_freq`.
- `plot_path_mission.py` no longer adds an invisible altitude reference series that expanded the altitude x-axis to path distance. The altitude axis is now time.
- `plot_path_mission.py` switches nearly straight ground-track plots to a y-axis zoom, so the lateral drift is visible instead of being compressed by equal aspect over a 180 m x-range.

## Difference From The Previous Retuned Plot

The previous `long_straight_final` plot was generated before fixing the logging-side double controller call. Compared with that old result:

| Metric | Old double-call log | New single-call log |
|---|---:|---:|
| min height error (m) | -0.3253 | -0.4093 |
| time to sustained 0.05 m band after min (s) | 4.7583 | 7.9667 |
| distance to sustained 0.05 m band after min (m) | 36.2750 | 61.2131 |
| time to zero crossing after min (s) | 6.6167 | 8.4167 |
| distance to zero crossing after min (m) | 51.0002 | 64.7999 |
| freq saturation fraction | 0.0821 | 0.0000 |
| elevon pitch saturation fraction | 0.0000 | 0.0000 |

Interpretation:

- The old retuned result was partially inflated by the script calling the stateful controller once for logging and again inside `env.step()`.
- With a single teacher update per env step, the same controller defaults are slower and no longer hit 5 Hz.
- This makes the next tuning target clearer: increase real TECS/inner-loop demand rather than relying on an accidental doubled controller update.

| `pitch_deg` | about 4.68-4.77 Hz |
| `vertical_support_ratio` | about 4.68-4.77 Hz |
| `pitch_sp_deg` | about 0.34-0.43 Hz |
| `freq_hz` | about 0.34-0.43 Hz |

Interpretation:

- High-frequency tail commands are still synchronized with the flapping-period attitude disturbance.
- TECS/pitch setpoint is not oscillating at that frequency; the high-frequency action is generated by the inner attitude loop.
- Adding tail filtering or lowering inner-loop update rate should be tested separately because it may reduce actuator chatter but can also slow altitude recovery.
