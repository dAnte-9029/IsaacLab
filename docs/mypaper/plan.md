# 扑翼飞行器周期占比调制（Duty-Cycle / SCCPFM）论文开展计划

## 0. 目标与定位（先定边界，避免跑偏）

- 论文主题：周期占比调制 `δ`（下扑占一个周期的时间比例）作为扑翼飞行器的控制输入。
- 主主张（核心一句话）：`δ` 通过“时间重参数化”改变半拍的瞬时角速度/加速度分配，从而在**不改变幅值/基频**的前提下显著改变周期平均 `Fx/Fz/Pin` 的权衡，并可用于闭环速度/推力调节。
- 形式：RA-L 风格短文（仿真为主 + 实机自由飞行闭环短验证 + 失败/偏差原因的 insight 讨论）。

## 1. 方法概念（写清楚 δ 到底改变了什么）

- 定义：`δ ∈ (0,1)` 为下扑时间占比（downstroke ratio）。
- SCCPFM/phase-warp：保持几何轨迹（幅值）不变，对时间轴做重参数化，使下扑用时 `δT`、上扑用时 `(1-δ)T`。
- 关键点：这不是“改轨迹”，而是“改时间尺度”，非线性气动（速度平方、相位相关迎角、分离开关等）会导致周期平均力/功率改变。

## 2. 仿真实验主线（现有代码即可支撑正文）

### 2.1 统一运动学定义

- 无调制与 `phase_warp, δ=0.5` 采用同一波形族（余弦基线），避免仅相位不同造成的平均偏差。
- 所有周期平均都用**整数周期**窗口：`dt=1/240`，在 `f=3.8Hz` 时用 `steps=1200`（5s=19 周期）。

### 2.2 理论 trim 基准点（模型内自洽，不等于实测 trim）

- 目标：`Fx ≈ 0`（自航/阻力平衡）且 `Fz ≈ mg`（升力平衡或至少在 mg 附近）。
- 当前已用扫参方式找到一个“trim-like”基准工况，并在此工况上展开 `δ` 扫描。
- 建议正文写法：
  - 主实验采用 `sep_off`（分离模型关闭）保证存在可复现的 trim/趋势。
  - `sep_on` 仅做敏感性与局限性讨论（stall 阈值不确定会导致 trim 不存在）。

### 2.3 δ 扫描（主结论来源）

- 固定基准工况与模型参数，扫 `δ ∈ [0.3,0.7]`（步长 0.02）。
- 输出：`Fx(δ), Fz(δ), Pin(δ), η(δ)`，并做 Pareto 前沿（多目标非支配点）总结最佳权衡集合。

### 2.4 必要消融（RA-L 够用，别做太多）

- `twist_off` vs `twist_on`：说明结构/被动扭转会改变 `δ → Fx/Fz/Pin` 的敏感性。
- `sep_on`：仅作为附录/讨论，展示 stall 阈值敏感性与为什么正文不把 `sep_on` 当主定量依据。

## 3. 实机自由飞行闭环短验证（写得出“好/不好”的两种版本）

### 3.1 最小可写的数据记录

- `δ_cmd(t)`、`f_cmd(t)`（若固定也记录）、功率/电流电压 `P(t)`、姿态、速度 `vx(t)`、高度（至少用于安全/控制）。
- 采样率建议 ≥ 50Hz，时间戳对齐。

### 3.2 闭环目标（与主张强对齐）

- 选速度/推力调节：`vx_cmd` 阶跃或跟踪，控制器输出 `δ`（限幅 `δ∈[0.3,0.7]`）。
- 对照：固定 `δ=0.5` 或传统输入（频率/尾翼）在同条件下的响应与能耗。

### 3.3 若实机效果不佳：把失败写成 insight（而不是删掉）

- 运动学实现误差：`δ_cmd` 与实际关节轨迹不一致（带宽、死区、饱和）。
- 结构耦合/膜翼相位滞后：扭转与迎角历史改变，导致力方向/幅值与仿真偏离。
- 估计/测量：`vx` 噪声/延迟导致闭环性能差。
- 结论定位：`δ` 作为输入可行，但工程上需要带宽/传感/结构模型支撑，给出清晰改进方向。
