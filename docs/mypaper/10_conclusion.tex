\section{Conclusion}
We studied duty-cycle (downstroke ratio) modulation as a low-dimensional control input for flapping-wing vehicles.
Using a phase-warped SCCPFM waveform and a quasi-steady strip-theory aerodynamic model in IsaacLab, we identified a trim-like baseline operating point and swept the downstroke ratio to quantify the resulting tradeoffs in cycle-averaged thrust, lift, and mechanical input power.
Results demonstrate that duty-cycle modulation provides a strong, nonlinear control lever near trim, enabling task-dependent thrust--lift--power tradeoffs.
We further described a Pareto-front extraction procedure for selecting non-dominated operating points under lift constraints and discussed hardware implementation considerations and a short closed-loop forward-speed regulation demonstration.
Future work will incorporate improved separation and aeroelastic models and broaden hardware validation.
