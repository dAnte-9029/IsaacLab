# Unified Trajectory RL：配平中心 PPO 初始化实验

## 结论与下一步

**SUPPORTED：初始化干预有效改变了探索分布与部分控制表现，但不足以消除学习后的横向退化或形成可靠终点控制。下一步选路线 B：研究学习目标的方向平衡、信用分配和终点目标。** 本轮不修改 reward，不自动续训。

- **A→M，均值作用：** Update 0 确定性平均存活从 2.087 增至 3.227 s，航程从 18.929 增至 31.986 m；共同前125步直飞 H/V 从 0.058/3.395 降至 0.026/0.775 m。M5 达到平均60 m投影，直飞早窗 H/V 为0.007/0.109 m。但首轮随机动作到trim距离仅从1.886变为1.876，裁剪仍约32%，M训练最初五次更新结束episode的平均存活没有改善（A/M=1.772/1.750 s）。均值居中改善初始确定性行为，不等于解决宽噪声探索。
- **M→B，低噪声增量：** 首轮 raw 到trim距离降至0.284，applied距离从1.206降至0.244，四通道裁剪为0。最初五次更新的训练结束episode平均存活增至2.651 s。B全程裁剪几乎消失，最终std为[0.169,0.173,0.167,0.172]，不是永久上限。可是B5冻结平均存活5.547 s，弱于M5的7.393 s；不能宣称低噪声普遍加速学习。后期B早窗水平误差和同状态漂移较M小，但简单直飞仍失败。
- **A→B，组合效果：** Update25平均停止前时长从3.697增至6.263 s，航程从30.746增至55.084 m；直飞前125步水平误差从0.522降至0.063 m，但垂直误差从0.130增至0.236 m。它是权衡改善，不是所有指标同时改善。B25五任务平均垂直误差0.455 m也高于A25的0.299 m。
- **VERIFIED，终点合同区别：** 18批共90条冻结轨迹，原协议仅B25 sustained记为完成。其400步/6.667 s停止，投影59.524 m，到当前投影点误差0.399 m，但到真实固定终点距离**0.620187 m**。实际代码要求“投影≥59.5 m且当前路径点误差≤0.5 m”，不是“真实终点距离≤0.5 m”。本轮未更改协议；按后者审计，所有组和更新点均为**0/5**，全部90条记录均未进入真实终点0.5 m球。B25协议早停后的表现未知。旧报告将原协议概括为真正末端误差判据并不准确，此处据源码与SQLite明确纠正，旧文件保持原样。

### 后期退化与机制边界

B10→B20 的直飞共同125步 H/V 从0.058/0.330变为0.093/0.114 m；全程 H/V 从2.442/1.604变为2.891/0.223 m。纵向改善与横向退化在共同窗口仍存在。B25早窗水平回落到0.063 m，但垂直回升到0.236 m，不能描述为持续单调退化或持续单调改善。B25除sustained外四条均在投影约53–55 m处横向越界，简单任务的终止横向偏差约8.042 m，未到末端。

M5→M25 直飞共同窗 H/V 从0.007/0.109变为0.176/0.051 m；M最初五次到最后五次更新的平均reward从0.03174升至0.05958，而冻结平均时长从M5的7.393降至M25的5.977 s，严格终点达标仍为0。B训练窗口reward从0.06660变为0.07372，但存活和航程非单调、横向误差上升、严格终点达标未出现。训练reward改善不能替代冻结控制证据。

原A在自身Update10状态上左尾均值漂移−0.360；M左尾−0.053、右尾−0.260；B左尾+0.065、右尾+0.028。不同组状态分布不能直接作孤立效应比较。因此另用M/B Update10固定状态并集3543条：Update25−10尾舵RMS漂移M为[0.260,0.410]，B为[0.087,0.047]。B没有复现A式左尾大幅漂移，但仍发生横向失稳；大幅左尾漂移不是全部失败的必要条件，也不能凭此归因到某个梯度机制。

B的std和entropy确实增大，但本轮没有分离entropy梯度与surrogate梯度，**UNRESOLVED：不能把增长单独归因于entropy项**。B25 sustained的路径跟踪明显优于其他任务，协议内完成且真实终点误差接近阈值；这不足以证明普遍转向能力，却也不支持“局部探索完全无法学会转向”。无额外探索宽度消融，不能确定探索过窄的因果影响。

频率仍受governor约93%–99%的控制步限速。B最后窗请求/governor/实际均值约2.957/2.954/2.954 Hz，M约2.864/3.082/3.082 Hz；不能把raw频率的大幅散布当成实际扑频同幅变化。

## 可比性与执行边界

A 复用历史 25 updates，仅额外执行一次 48-step rollout/PPO 复现核对。初始 digest、12,288 条逐步物理与动作证据（仅剔除运行版本号）、reward、loss、参数变化量及结束事件完全一致。M/B 各 256×48×25=307,200 transitions，合计新增正式训练 614,400；验证 rollout 单独记录，未重训 A。

网络、39D/4D、PPO 数学定义、reward、任务、物理与执行器未变。初始化只修正 actor.6.bias；B 额外将可学习 std 初始化为 0.15。真实 M/B reset 观测、Actor/Critic 权重和 bias 偏移逐 tensor 配对检查。Update 0 是各组真实训练策略保存，不在评价环境重算。

A 的物理合同包含旧绝对资源路径，第一次跨 worktree 补评被拒绝且未执行控制步；失败目录保留。A 补评改用原入口，输出仍在新目录。两工作区物理合同的差异仅资源路径，物理源码/URDF 指纹一致，且首轮逐步数值完全一致。没有放宽物理校验。

训练配置：CPU-native PhysX 480 Hz、control 60 Hz；256 env、48 rollout steps、25 updates、5 epochs×4 minibatches、lr 3e-4、threads=1；save=5、正常 eval=25、development 上限7200 steps/env。未执行 final 六条任务。
