# ULLT：可能需要修正的东西

日期：2026-10-27。配套[第一阶段交接](../handoffs/2026-10-27-ullt-stage1.md)。
这是后续改进清单，不表示已批准修改正式训练基线；当前 DeLaurier 默认保持不变。

2026-10-27 已完成[首轮实飞三方比较](../audits/2026-10-27-ullt-flight-comparison.md)：
25 次飞行的输入选定窗口中，ULLT-4 的 Fx/Fz/My 误差均高于冻结 DeLaurier；Fz 主谐波相位略好。
每行最大局部迎角 P95 为 66.91°。单窗面元加倍仍有约 2–5% 载荷差，步长/初始化敏感性较小。
这些结果提高了大迎角、布翼运动学和标签敏感性的检查优先级，没有据此标定或改变物理模型。

## 当前用途与证据

当前后端用于规定运动下的气动力研究，支持准定常、1/4/6 状态选择。
CSV 实翼使用 1/4 状态；6 状态的附加下洗修正只开放给直线、共面、无后掠的升力线。
参数是薄平板附着流先验，没有翼型极曲线或实测气动力支撑。
通过数值测试不等于真实机翼验证，也不等于已经可以接入自由飞行训练。

下表的“通过条件”是建议的后续验收内容；涉及新物理假设、公开接口或默认基线时，仍需明确批准。

## 优先改进项

| 项目 | 当前处理及可能后果 | 什么时候需要改；需要什么 | 建议验证方式 |
|---|---|---|---|
| **大迎角分离、前缘涡和失速** | 线性截面升力斜率 `2π/rad`；没有分离状态。8 m/s、30° 刚性扑动的 2/4/5 Hz 检查中最大局部几何迎角约 31.89/51.22/57.27°，附着流先验可能明显失效 | 在用实翼载荷预测平均升力、推力或设计控制之前；需要适用雷诺数的测力/流场数据，或经过验证的高保真参考 | 独立留出的频率、幅值、速度工况；比较周期均值、幅值、相位和峰值，不能只比较是否数值稳定 |
| **布翼弯度、前缘碳管与被动俯仰** | 零弯度薄板，无结构顺应性；前缘是几何参考，不是已建模的独立俯仰自由度。可能错估零升力角、载荷相位和气动功率 | 如果观测到碳管转动/布面鼓起；需要同步视频或标记点运动、截面形状，必要时测刚度、阻尼、预紧和限位 | 先验证运动学/静态挠度，再验证气动；将被动俯仰与气动系数误差分开 |
| **展向扭转（已授权离线小样本试验）** | 可选 Quadratic-2 规定扭转，更新前缘转动后的几何、速度、加速度与力矩；默认仍为零扭转。参数尚非实测 | 三条训练日志、六组固定参数的诊断见 [审计](../audits/2026-10-27-ullt-twist-screen.md)；结构参数、实际扭角与展向相位延迟仍待测量 | 零幅值回归、镜像与有限差分检查；需进一步验证投影截面近似、展向分辨率、独立飞行及测量一致性 |
| **翼展离散误差** | 余弦边界、面元中点和分段常值环量。椭圆翼稳态相对 Prandtl 解析升力斜率误差：9/17/33/65/129 面元为 5.678/2.963/1.511/0.763/0.383%。目前近似一阶收敛，尚未达到论文报告的低面元精度 | 进行低成本高精度计算前；不需要用户额外数据，需核对配点、环量表示及端点处理 | 独立解析椭圆翼基准、空间加密及非定常加密；不要靠修改 `Clα` 抵消离散误差 |
| **论文独立对照** | 已生成第三节 A–D 的运动算例，并有解析/频域测试；没有导入作者 UVLM 原始曲线。第四节鸟式扑动和第五节实验未完整复现 | 宣称复现论文误差或验证非定常推力之前；获取可追溯数值数据，或明确精度限制的图像数字化数据 | 统一坐标、初态、无量纲化、时间和面元收敛；逐点比较升力、推力、环量及相位 |

## 后续实现和标定项

| 项目 | 当前处理及可能后果 | 触发条件／所需输入 | 建议通过条件 |
|---|---|---|---|
| 剖面阻力 | 论文对照及当前 CSV 检查 `Cd=0`；API 支持非负常数。未计布面/碳管黏性阻力，推力和耗功可能偏乐观 | 有极曲线或测力数据，或要讨论续航/净推力 | 多速度、雷诺数、迎角的独立对照；避免与诱导阻力重复计入 |
| 附加质量因子 | 论文 AR=3 示例 `Kam=0.85`；实翼暂用 `1.0`，没有针对实翼标定 | 要精确预测加速度载荷或机构力矩时 | 升沉/俯仰幅相、交叉惯性项及能量一致性；系数不能随意拿来拟合环量误差 |
| 实翼的 6 状态修正 | 对非共面/弯曲升力线显式拒绝；1/4 状态已有跨左右翼诱导流，但没有附加 3D 非定常下洗修正 | 1/4 状态与高保真参考出现系统性瞬态误差时 | 先推导几何适用性，再用独立涡环结果验证；不能直接把直翼矩阵套到扑动实翼 |
| Appendix B 拟合选择 | C1/C2 用无量纲行程 0–15 上 301 点等权最小二乘，非作者未公开的精确表 | 对拟合窗口/权重敏感或残差影响主要载荷时 | 窗口和采样加密敏感性、稳态抵消、独立有限涡环核对；记录算法和系数来源 |
| 后掠截面与弦线解释 | 以 CSV 的 1/4 弦线定义局部展向；原始弦长投影到该展向的法向，面积按局部宽度积分 | 曲线变化明显或需要与另一几何建模方法比对时 | 保留 CSV 原始站位、面积及根部坐标；比较不同合理离散方式，不能悄悄缩短翼展 |
| 低速、反流与尾迹卷起 | 弦向相对气流近零/反向显式报错；尾迹方向来自瞬时运动，没有历史尾迹卷起/捕获 | 悬停、反向运动或强尾迹交互 | 先明确适用理论；这些情况不能靠加速度/空速下限夹紧来宣称有效 |
| 自由体附加质量耦合 | 仅接受规定的解析加速度，未读取滞后一帧的 PhysX 加速度来施加载荷 | 下一阶段要接自由飞行环境 | 先制定质量矩阵/隐式耦合合同；检验动量、能量、时间步收敛和有/无气动配对，不重复计入惯性 |
| 运行性能与 GPU | 批量 Torch 接口；每次载荷调用求解稠密系统，6 状态重复构造拟合；当前只有 CPU 验证，CUDA 测试跳过 | 需要大批量或实时运行时 | 先确保 CPU/GPU 一致、部分重置无串扰，再缓存几何不变量/优化求解；报告真实吞吐，不能以精度换速度而不说明 |
| 气动功率与电功率 | API 输出相对空气的理想机械气动功率，没有机构惯性损耗、电机、减速器和电池模型 | 讨论电耗、扭矩裕度或续航 | 区分气动做功、机械总功率和电功率；需要机构参数及同步电流、电压/扭矩数据 |

## 后续顺序

1. 先改善翼展离散并补齐独立论文曲线对照，不需要修改用户机翼几何。
2. 对实翼开展规定运动的空间/时间收敛和气动敏感性分析；当前六个实翼算例只验证几何接线与有限数值，没有实翼收敛或准确性结论。
3. 如果目标是接入自由飞行，单独确定附加质量耦合方案并做载荷/动量验证，然后增加显式选择入口。
4. 当测量可用时再逐项加入阻力、弯度、被动俯仰和扭转；正式训练默认是否切换另作决定。

现有几何决策不在待修正清单内：翼根使用 URDF 的 ±56 mm，CSV 从各翼根向外完整排列；中间没有升力面元，左右翼仍相互诱导。只有用户提供替代几何或明确修订坐标定义才重开该决策。
