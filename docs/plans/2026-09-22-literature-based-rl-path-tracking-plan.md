# 扑翼飞行器 RL 轨迹跟踪：基于文献的实施计划

日期：2026-09-22。

本文整理此前文献检索形成的技术路线，并单独记录后续实验反馈。文献提出的方法、项目中的工程改编、已经验证的结果和待验证的建议分别陈述，避免把计划当成完成证明。

适用工作树：`.worktrees/native-multibody-rl`，分支 `feat/native-multibody-rl`。本文是总体计划；已批准的实验合同见 [C4 课程与保持能力 ADR](../decisions/ADR-2026-09-22-c4-retention-curriculum.md)，实现与运行入口见 [实验交接](../handoffs/2026-09-22-c4-retention-pilot.md)。

## 1. 最终目标与问题定义

1. 先在当前无风仿真中训练一个统一 RL 控制器，跟踪模型能力范围内的连续三维轨迹。
2. 无风跟踪与旧能力保持通过后，再加入风场，训练抗扰能力。

“任意轨迹”指经过可行性约束的轨迹族及其未见组合，不指不受速度、曲率、爬升、执行器能力限制的任意数学曲线。路径几何筛选仅提供候选范围，不能替代闭环动力学验证。

当前核心困难是：直接学习宽分布轨迹过难；依次切换课程，又会使后续更新破坏已经掌握的能力。因此计划同时处理两个问题：**如何分配训练难度，以及如何限制已学行为的退化。**

## 2. 文献依据与项目采用方式

### 2.1 连续任务分布上的自步课程

[Self-Paced Deep Reinforcement Learning，Klink 等，2020](https://arxiv.org/abs/2004.11812)研究逐步调整任务分布，使课程与学习能力相适应并向目标分布推进。

提炼出的工程原则：把课程定义为轨迹参数的采样分布，不再只依次切换“直线、转弯、爬升”等互斥阶段。控制难度增长速度，同时保留已学区域的覆盖。

本项目先在温和 C4 范围内调整曲率与坡度幅值采样，验证稳定性后才扩大范围。当前四区域采样器是离散工程改编，不是原论文优化算法的复现。

### 2.2 按学习进展分配训练样本

[Teacher algorithms for curriculum learning of Deep RL in continuously parameterized environments，Portelas 等，2019](https://arxiv.org/abs/1910.07224)提出包括 ALP-GMM 在内的教师算法，用学习进展组织连续参数环境的课程。

提炼出的工程原则：优先练习仍在学习或发生退化的区域，避免持续投入完全不会或已经长期稳定掌握的区域；保留探索与最低覆盖。

本项目使用成功率、前后窗口变化和最低采样概率，不实现 GMM，也不声称等价于 ALP-GMM。反馈只来自训练，不能读取固定评估案例来决定下一条训练轨迹。

### 2.3 用经验记忆保持旧行为

[Experience Replay for Continual Learning（CLEAR），Rolnick 等，NeurIPS 2019](https://papers.neurips.cc/paper_files/paper/2019/hash/fa7cdfad1a5aaf8370ebeda47a1ff1c3-Abstract.html)将经验回放、离策略学习和行为克隆结合，用于减少持续 RL 中的遗忘。

提炼出的工程原则：仅在当前策略访问到的状态上训练，不足以确保旧行为保持；需要保存旧状态与行为，并在后续训练中持续约束。

为兼容当前 PPO，首轮仅引入冻结训练观测和教师动作均值的辅助损失。旧样本不进入 PPO 比率估计或价值回归。这不是完整 CLEAR，也没有保护教师动作方差和 critic。是否需要更强约束，由保持能力评估决定。

### 2.4 备用路线：专家与统一策略之间的蒸馏

[Distral: Robust Multitask Reinforcement Learning，Teh 等，2017](https://arxiv.org/abs/1707.04175)通过共享蒸馏策略与任务策略之间的联系进行多任务 RL。

它为“先让不同任务策略学会，再向统一策略汇总”的备用路线提供参考。若统一策略长期出现不可接受的任务干扰，可研究分任务专家与共享学生；但专家到学生的保持能力仍必须重新评估。这是备用方向，不是当前已实现方案，也不意味着部署时采用任务切换器。

### 2.5 综合选择

优先路线为：**持续混合旧任务＋连续轨迹分布课程＋成功行为记忆＋固定保持能力评估**。

课程解决“练什么”，记忆解决“保留什么”，更新诊断解决“为什么仍在丢失”。文献提供方法依据，不保证该组合在当前扑翼模型上成功。

## 3. 实验共同边界

- 使用 CPU-native measured-wing PhysX 作为训练与验收依据；保持 480 Hz 物理、60 Hz 策略控制。
- 保持 555 维观测、四动作接口及现有 split actor；旧任务与 C4 保留各自的预览语义。
- 初始保持实验不同时修改物理参数、奖励、网络规模或执行器限制。
- 每个新机制均显式启用，原始基线仍可运行。
- 训练、开发评估、最终 holdout 分开。训练采样和记忆不得使用评估轨迹。
- 开发集用于方法选择；holdout 在候选和选择规则冻结后才使用，不反复用于调参。
- 所有比较报告环境交互量、种子、优化器起点、记忆采集开销和输入/代码哈希。

研究初始化是 full-C3 `model_175.pt`。它曾单次通过五套旧任务，但缺少相邻通过检查点，因此不能当作正式晋级基线。

## 4. 分阶段执行计划

### 阶段一：建立可复现的保持能力诊断

目的：区分训练运行正常、策略存活和真正学会跟踪。

工作内容：

1. 冻结 C4 开发曲线集与旧任务 C1/C2c/C3a/C3b/C3c 评估合同。
2. 保存终止前状态、轨迹误差、完成进度、实际动作、饱和和终止原因。
3. 记录分任务 PPO 梯度、尾翼梯度夹角、更新后 KL、动作变化和 critic 残差。
4. 保留研究初始化和中间检查点；必要时做相同观测下的策略比较与通道替换。

完成条件：评估可在新进程复现，模型与观测/动作对应关系可核对，失败也输出完整结果。训练奖励或存活率不能替代验收。

### 阶段二：在温和分布内比较课程与行为记忆

首先固定 C4 候选范围：航向变化率幅值 `0.005–0.009 rad/m`，坡度幅值 `2–4°`；其余几何筛选与采样范围沿用现有合同。

| 组别 | C4 分布 | 行为记忆 |
| --- | --- | --- |
| A | 固定 | 无 |
| B | 自适应 | 无 |
| C | 固定 | 有 |
| D | 自适应 | 有 |

课程实现要求：

- 在曲率/坡度幅值构成的四个区域内调整采样，每区概率至少 10%，每次变化不超过 0.05。
- 仅根据已完成训练回合更新，失败也必须计入；记录反馈延迟和各区样本数。
- 保持六任务 PPO 目标权重不变。当前 task-aware PPO 会按目标权重重标定优势，仅调整外层 reset 比例不等于改变任务梯度权重。

记忆实现要求：

- 从冻结教师的新训练 rollout 收集成功回合，按六类任务平衡保存观测和动作均值。
- 使用独立随机数状态、容量限制、来源哈希和断点恢复。
- 首轮辅助动作均值 MSE 系数为 1.0，仅是预声明实验值，不是最优结论。
- 另行记录每任务、每动作通道的保持误差，不能只看平均辅助损失。

首轮预算：每组 seed 0、101 次迭代、256 环境、48 步 rollout、16 minibatch；同一源权重、全新优化器。检查点 50/75/100 均执行 C4 与全部五套旧任务评估。记忆采集开销单列。

### 阶段三：失败时先隔离原因，再做小规模修正

若四组没有完整通过：暂停范围扩张，依次检查策略均值/方差漂移、记忆覆盖、任务梯度、critic 估计、奖励与跟踪指标关系以及课程反馈时延。

根据证据选择单一主要变化：

- 若更新累积破坏可用动作，比较更小的更新幅度或明确的行为保持约束。
- 若记忆覆盖不足，补充独立训练中的恢复状态与边界状态；不能将开发轨迹复制进记忆。
- 若任务冲突有足够证据，再研究梯度处理、分任务价值估计或专家蒸馏，避免同时引入多个架构变化。

每次实验先写明假设、对照、预算、停止条件和通过门槛。发生退化不通过放宽门槛“修复”结果。

### 阶段四：逐步扩大无风轨迹覆盖

进入条件：温和分布有相邻检查点同时通过新旧任务。

逐项增加曲率、坡度、变化频率及其组合；每次扩张保留旧范围与旧任务样本。先做几何/运动学筛选，再验证闭环能力，记录因不可行而拒绝的轨迹，不能把所有失败都归于控制器。

目标评估包括未见参数组合、曲率与爬升连续变化、方向镜像、不同初始航向和扑翼相位。若有限预览不足以区分控制需求，先提供观测混淆证据，再讨论观测接口修改。

### 阶段五：多种子与最终无风验收

对选定方案冻结超参数和选择规则，执行预先确定的多种子验证（建议至少三个），报告每个种子的完整结果，不能只展示最佳种子。

开发阶段仍要求样本等价间隔下的相邻检查点通过；候选冻结后进行独立 holdout 验证。最终结论限定为已覆盖的可行轨迹分布，不能据有限测试声称所有曲线均可控制。

### 阶段六：加入风场与抗扰训练

进入条件：无风控制器已通过上一阶段。

先定义风场与气动相对速度接口，以及有依据的扰动范围；随后从弱稳态风、不同风向逐步扩展到时变风和阵风。继续混合无风任务与记忆，防止抗扰训练破坏原有能力。

风场分布、观测可用性和幅值边界需单独形成合同，当前计划不预设未经验证的风速。验收同时包含无风保持、已训练风分布、未见风向/变化组合和执行器余量。

## 5. 验收与停止条件

验收同时检查：存活、轨迹完成、水平/垂直平均及 P95 误差、任务子集成功率、倒飞/反向运动、姿态限制和执行器相关门槛。

当前 C4 开发门槛包含平均水平/垂直误差不超过 0.5 m、对应 P95 不超过 1.5 m，并同时检查完成率、成功率与各子集；完整逻辑以 `analysis/c4_training_evaluation.py::c4_tracking_gate` 为准。旧任务使用各自冻结门槛，不能把 C4 门槛套到全部任务。

只有两个符合样本间隔要求的相邻检查点同时通过六套评估，才获得进一步验证资格。数值非有限、日志不完整、合同不匹配属于运行/证据失败；数值正常但跟踪不通过属于方法失败，两者分开报告。

## 6. 截至本次整理的执行状态

以下为实施后的反馈，不是原文献结论：

- 阶段一及阶段二已完成实现、预检和四组正式实验。128 项单元/合同测试、真实仿真重置与恢复验证通过。
- 四组均完成 101 次迭代，正式训练共 4,964,352 transitions；成功行为记忆共 24,576 条，采集另消耗 614,400 transitions。
- C/D 在检查点 50 达到 C4 96/96，但到 75 四组均为 0/96。没有检查点同时通过六套验收，因此仍停留在阶段三。
- D-50 仅差 C3b 平均水平误差门槛：0.50599 m 对 0.500 m；不能据此放宽门槛。
- 诊断中，D-75 频率＋D-50 尾翼恢复 96/96，反向组合为 0/96，定位了直接行为退化；尚未证明训练层面的唯一根因。
- 当前最近的待执行训练建议是减小尾翼更新幅度的受控对照，同时提高保持能力监测频率。具体预算、更新参数及约束规则尚未冻结，也未启动这轮训练。
- 阶段四至六尚未开始，holdout 未打开，未添加风场。
