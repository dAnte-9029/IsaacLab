## 📏 你可以从 SolidWorks 直接补给我的量

### 对 `left_elevon`、`right_elevon`、`rudder`，我建议你量这些

| 参数 | 该量哪一块 | 具体怎么量 | 不要包含什么 |
| --- | --- | --- | --- |
| `projected_area_m2` | 只量**活动舵面本体** | 把该舵面放在中立位置，取它在自身弦向-展向平面内的投影面积，也就是通常说的舵面平面形面积 | 不要把固定平尾 / 固定垂尾、机身、铰链支座并进去 |
| `span_m` | 只量**活动舵面的展向长度** | 对 elevon，量沿铰链线方向、从根部到翼尖方向的有效长度；对 rudder，量沿铰链线方向、从下到上的有效高度 | 不要量机身里的埋入段，也不要把固定面一起算进去 |
| `mean_chord_m` | 只量**活动舵面的平均弦长** | 最稳妥的做法是直接用 `projected_area_m2 / span_m`；如果 SolidWorks 能直接给平均弦长，也可以直接给 | 不要用固定面加活动面的总弦长 |

### 具体到三个面，建议这样理解

| 面 | `projected_area_m2` 应该是哪块 | `span_m` 应该是哪段 | `mean_chord_m` 应该对应哪种弦长 |
| --- | --- | --- | --- |
| `left_elevon` | 左侧**可动平尾舵面**自身面积 | 左侧可动平尾沿铰链线方向的有效长度 | 左侧可动平尾的平均弦长 |
| `right_elevon` | 右侧**可动平尾舵面**自身面积 | 右侧可动平尾沿铰链线方向的有效长度 | 右侧可动平尾的平均弦长 |
| `rudder` | **可动方向舵**自身面积 | 方向舵沿铰链线方向的有效高度 | 方向舵的平均弦长，也就是前后向平均宽度 |

## 🧭 气动中心和安装角的建议约定

### `aerodynamic_center_body` 怎么取

| 项目 | 建议 |
| --- | --- |
| 选用理论 | 采用低速、小迎角、准定常薄翼面近似 |
| 具体位置 | 取各个舵面**中立位置**下的 **1/4 弦长点（quarter-chord point）** |
| 对非矩形舵面 | 取 **MAC（平均气动弦）25% 位置** 对应的代表点 |
| 这意味着什么 | 你只需要给我舵面几何，我就可以按这个理论把 `aerodynamic_center_body` 定下来，不一定非要你在 SolidWorks 里手量这个点 |

### `incidence_rad` 是什么

| 项目 | 说明 |
| --- | --- |
| 定义 | 舵面或尾翼在**零舵偏**时，其参考弦线相对机体系基准方向的安装角 |
| 你这个情况 | 如果你说“尾翼都是平着安装”，而且中立位就是几何上的零偏角，那当前完全可以按 `incidence_rad = 0` 处理 |
| 什么时候不是 0 | 如果 CAD 里本来就带固定上反/下反、预设配平角，或者零关节角不等于气动中立位，那就不是 0 |

## 🧩 前面说的“三个拆分”是什么意思

| 名称 | 实际意思 | 为什么会出现这个问题 |
| --- | --- | --- |
| 固定平尾几何拆分 | 把 `base_link` 里属于**固定平尾**的那一部分几何单独拿出来 | 现在导出的 URDF 里，固定平尾没有单独 link，而是和机身合在 `base_link` 里 |
| 固定垂尾几何拆分 | 把 `base_link` 里属于**固定垂尾**的那一部分几何单独拿出来 | 现在导出的 URDF 里，固定垂尾也没有单独 link，而是和机身合在一起 |
| 固定尾翼质量 / 质心 / 惯量拆分 | 把“机身 + 固定尾翼”这一整块的惯性，拆成“机身本体”和“固定尾翼本体”两部分 | 当前 URDF 只给了整个 `base_link` 的总质量、总质心、总惯量，没有单独给固定尾翼 |

### 更直白一点

现在的文件结构更像这样：

- `base_link = 机身 + 固定平尾 + 固定垂尾`
- `left_tail = 左活动舵面`
- `right_tail = 右活动舵面`
- `rudder = 活动方向舵`

所以：

- 活动舵面这三块，我们已经能直接读
- 固定平尾和固定垂尾，因为被包在 `base_link` 里面，所以暂时没法单独知道它们各自的面积、质心、惯量

## 🧾 新尾翼模型输入草表

### 1. 这批信息现在是否已经足够

结论：**足够了。**

基于目前已知信息，已经可以把新尾翼的几何和位置整理成模型输入：

- `fixed_horizontal`
- `left_elevon`
- `right_elevon`
- `fixed_vertical`
- `rudder`

本阶段先把它们作为**薄板参考面**输入气动模型：

- 面积、展长、平均弦长、安装角、气动中心都可以定
- 分块质量 / 质心 / 惯量先不强制接进模型
- 厚度 `5.85 mm` 暂时只作为装配备注，不作为第一版气动参考面主输入

### 2. 统一局部坐标定义

#### 2.1 平尾局部坐标

右平尾多边形 `right_elevon_polygon.py` 采用如下局部坐标：

| 局部量 | 含义 | 单位 |
| --- | --- | --- |
| `s_mm` | 沿铰链线，从内侧到外侧 | mm |
| `c_mm` | 沿机体前向，朝前为正 | mm |

对应关系：

- 铰链线：`c_mm = 0`
- 固定平尾：`c_mm >= 0`
- 右侧 elevon：`c_mm <= 0`

#### 2.2 垂尾局部坐标

垂尾多边形 `vertical_polygon.py` 采用如下局部坐标：

| 局部量 | 含义 | 单位 |
| --- | --- | --- |
| `a_mm` | 垂尾截面里的前后向坐标，`a_mm < 0` 更靠前，`a_mm > 0` 更靠后 | mm |
| `h_mm` | 沿铰链线，从下到上 | mm |

对应关系：

- 铰链线：`a_mm = 0`
- 固定垂尾：`a_mm <= 0`
- `rudder`：`a_mm >= 0`

### 3. 机体系锚点与坐标变换

#### 3.1 已确认的 URDF 锚点

| 关节 | URDF 含义 | 机体系坐标 m |
| --- | --- | --- |
| `right_tail` | 右平尾铰链**中点** | `(-0.5365, -0.15, -0.00335)` |
| `left_tail` | 左平尾铰链**中点** | `(-0.5365, 0.15, -0.00335)` |
| `rudder` | 垂尾铰链**最下点** | `(-0.5045, 0.0, -0.00085)` |

#### 3.2 右平尾坐标变换

右平尾局部点 `(s_mm, c_mm)` 放到机体系后：

```text
X_body = -0.5365 + c_mm / 1000
Y_body = -0.1500 + (150 - s_mm) / 1000
Z_body = -0.00335
```

因为铰链长度正好是 `300 mm`，它也可化简为：

```text
X_body = -0.5365 + c_mm / 1000
Y_body = - s_mm / 1000
Z_body = -0.00335
```

#### 3.3 左平尾坐标变换

左平尾和右平尾镜像对称，因此：

```text
X_body = -0.5365 + c_mm / 1000
Y_body = s_mm / 1000
Z_body = -0.00335
```

#### 3.4 垂尾坐标变换

垂尾局部点 `(a_mm, h_mm)` 放到机体系后：

```text
X_body = -0.5045 - a_mm / 1000
Y_body = 0
Z_body = -0.00085 + h_mm / 1000
```

这里按你的最新确认处理：

- `rudder` 的 URDF 原点是铰链最下点
- 垂尾整体都在这个点的上方

### 4. 五部分几何输入表

| 部件 | 几何来源 | 分割规则 | 面积 mm² | 面积 m² | 展长 / 高度 m | 平均弦长 m | 安装角 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `fixed_horizontal` | 由右平尾多边形在 `c_mm >= 0` 的部分镜像到左侧后合并 | 右固定面 `c_mm >= 0`，左侧镜像 | `2 * 26950 = 53900` | `0.0539` | `0.600` | `0.0539 / 0.600 = 0.0898333` | `0` |
| `right_elevon` | 右平尾多边形在 `c_mm <= 0` 的部分 | `c_mm <= 0` | `20390` | `0.02039` | `0.300` | `0.02039 / 0.300 = 0.0679667` | `0` |
| `left_elevon` | 右侧 elevon 镜像 | 右侧镜像 | `20390` | `0.02039` | `0.300` | `0.0679667` | `0` |
| `fixed_vertical` | 垂尾多边形在 `a_mm <= 0` 的部分 | `a_mm <= 0` | `12650` | `0.01265` | `0.170` | `0.01265 / 0.170 = 0.0744118` | `0` |
| `rudder` | 垂尾多边形在 `a_mm >= 0` 的部分 | `a_mm >= 0` | `10140.4` | `0.0101404` | `0.170` | `0.0101404 / 0.170 = 0.0596494` | `0` |

### 5. 气动中心的输入约定

| 部件 | 约定 |
| --- | --- |
| `right_elevon` | 由 `c_mm <= 0` 的活动面几何，按中立位下的 `1/4 chord` / `MAC 25%` 计算 |
| `left_elevon` | 右侧镜像 |
| `rudder` | 由 `a_mm >= 0` 的活动面几何，按中立位下的 `1/4 chord` / `MAC 25%` 计算 |
| `fixed_horizontal` | 由左右固定平尾合并后的对称几何计算，结果应落在机体中面对称线上 |
| `fixed_vertical` | 由 `a_mm <= 0` 的固定垂尾几何计算 |

这意味着：

- 你现在不用再额外手量 `aerodynamic_center_body`
- 用现有多边形和已知坐标变换，就能按选定理论直接算出来

### 6. 关于厚度 `5.85 mm`

| 项目 | 当前处理 |
| --- | --- |
| 气动参考面 | 第一版按**薄板中面**处理，不把厚度直接写进主气动输入 |
| 装配关系 | 你提到的“垂尾居中放置，取半厚度才和平尾顶点真正重合”这条，保留为后续 3D 装配修正备注 |
| 是否阻塞当前建模 | 不阻塞 |

### 7. 当前还不需要你再补的东西

现在先**不需要**你再补这些：

- 分块质量
- 分块质心
- 分块惯量

原因是第一版尾翼气动输入已经足够形成，质量惯量只会增加复杂度，不会明显提升当前这一步的有效性。
