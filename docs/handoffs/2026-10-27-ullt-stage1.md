# ULLT 第一阶段：规定运动后端与验证

日期：2026-10-27。分支：`feat/ullt-state-space-wing-aero`。
基底及当前 HEAD：`a7b3e08e0c1e`；本文记录的实现尚未提交。

## 完成范围

实现 Izraelevitz 2017 的独立 Torch 气动后端，保留原 DeLaurier、机器人资产、环境注册和 RL 默认。
通过 `ULLTConfig(model=...)` 显式选择 `quasi_steady`、`one_state`、`four_state` 或 `six_state`。
第一阶段的“可切换”是独立 API/验证 CLI 中的模型选择，尚不是正式环境中的气动后端切换。

实现内容包括：三维拖曳涡诱导矩阵、截面非定常升力/环量状态、受限几何的 6 状态下洗修正、
平板附加质量及 anti-Munk 项、力矩换点、相对空气的机械气动功率，以及显式逐环境状态/部分重置。
外部提供规定运动；`evaluate` 不推进状态，`advance` 使用各 RK4 子阶段对应的几何与运动输入。

几何按[已批准的根部/CSV 合同](../decisions/ADR-2026-10-27-ullt-urdf-root-local-csv-geometry.md)：
URDF 根部 ±56 mm，完整根部局部 CSV（推断单翼长度 0.700 m），不扣除文件名中的 gap50，
不添加中心空隙面元；左右翼之间的诱导仍保留。当前无动态扭转和额外前缘被动俯仰自由度。

完整物理先验、坐标、公式歧义处理及数值选项见
[阶段 ADR](../decisions/ADR-2026-10-27-ullt-stage1-prescribed-motion.md)。
用户要求记录的后续修正内容见[改进清单](../plans/2026-10-27-ullt-model-improvements.md)。

## 代码入口

| 文件 | 责任 |
|---|---|
| `source/flapping_bot/flapping_bot/config/ullt.py` | 不可变 `ULLTConfig`，显式物理先验与数值边界 |
| `source/flapping_bot/flapping_bot/physics/ullt_state_space.py` | `ULLTGeometry/Motion/State/Loads`；`ULLTBackend` 状态与载荷 API |
| `source/flapping_bot/flapping_bot/physics/ullt_geometry.py` | 椭圆翼、CSV/URDF 几何、解析刚体运动与左右相反扑动 |
| `source/flapping_bot/flapping_bot/analysis/ullt_validation.py` | 论文第三节规定运动、解析稳态和时间步加密、实翼数值检查 |
| `scripts/flapping_px4/validate_ullt_stage1.py` | 独立 CLI，配置/源码/几何哈希、JSON、NPZ、载荷图 |
| `tests/test_ullt_state_space.py` | 解析、频域、独立涡核、几何/坐标/状态与输入边界测试 |

标量数组形状 `(B,N)`，矢量 `(B,N,3)`，状态 `(B,N,K)`；支持显式 float32/float64、device。
所有量使用 SI，同一惯性系；入流为“空气速度减截面速度”。力是面元积分后的 N，不是 N/m。
力矩输出的参考点必须显式给出；环量/附加质量载荷分别按 1/4 弦点与 3/4 弦点及自由力偶组装。
`power_input_w` 是理想机械气动功率，不是电功率。

简短 API 示例（从零尾迹开始的椭圆翼俯仰）：

```python
from flapping_bot.config.ullt import ULLTConfig
from flapping_bot.physics.ullt_state_space import ULLTBackend
from flapping_bot.physics.ullt_geometry import elliptic_geometry
from flapping_bot.analysis.ullt_validation import paper_motion

geometry = elliptic_geometry(num_sections=17)
sample, duration, origin = paper_motion("pitch", geometry)
backend = ULLTBackend(ULLTConfig(model="four_state", added_mass_factor=0.85))
state = backend.zero_state(geometry)
dt = duration / 384
state = backend.advance(state, sample, time_s=0.0, dt_s=dt)
geometry, motion = sample(dt)
loads = backend.evaluate(geometry, motion, state, reference_w_m=origin(dt))
```

`steady_state(geometry, motion)` 是另一种初始条件；不能与零尾迹起动混用。
近零/反向弦向气流、奇异涡线、非有限值和不支持的 6 状态几何显式失败。
没有静默回退为旧模型、空速夹紧或隐藏状态推进。

独立检查包括：解析 2D 阶跃、独立复频域响应、Prandtl 椭圆翼稳态、有限涡环与拖曳涡符号、

坐标旋转/力矩参考点平移、批次与部分重置、输入拒绝、CSV 完整跨度和非零扑动镜像对称。
没有运行 Isaac Sim 自由飞行、控制器评估或训练；测试通过不扩展为这些层面的结论。

数值报告的范围：

- 论文第三节 A–D：起动、变速、俯仰、升沉—俯仰，4 种模型共 16 个算例；9 面元，384 步覆盖完整轨迹。
  除起动算例外是 3 周期；起动时刻的奇异附加质量冲量未离散，记录的是起动后的常规载荷。
- 俯仰步长减半：按力、力矩、环量分别归一化，最大相对差约 `1.24e-8`，低于 `1e-3` 门槛。
  这只是该俯仰算例的时间积分检查，不是任意运动下的稳定性保证。
- 椭圆翼空间加密：9 面元升力斜率误差 **5.678%**，129 面元 **0.383%**，单调减小。
  当前分段常值离散未达到论文低面元精度；9 面元曲线是研究对照起点，不是收敛真值。
- 实际 CSV/URDF：每翼 10 面元；8 m/s、30°、2/4/5 Hz，1/4 状态共 6 个单周期检查均有限。
  最大局部几何迎角约 **31.89/51.22/57.27°**，不能把数值通过解释为大迎角气动正确。
