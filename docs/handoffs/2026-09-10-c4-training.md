## Commands

```bash
source /home/zn/anaconda3/etc/profile.d/conda.sh

export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 TERM=xterm
```

Formal training **prepared, not run** (choose a new output directory):

```bash
./isaaclab.sh -p scripts/flapping_px4/train_continuous_curve.py \
  --weights logs/rsl_rl/flapping_bot_straight_flight/2026-09-01_10-13-43_pure_rl_c3_full_joint_from_c2c_seed0_301iter/model_175.pt \
  --output logs/continuous_curve/c4_joint_seed0
```

Smoke adds `--smoke`. Resume uses `--resume <C4 model_N.pt>` instead of `--weights`,
with the same seed/env/rollout/minibatch contract and a new output directory.
`--iterations` is the number of additional iterations. No simulation snapshot is
restored; episodes restart. Checkpoint index N is zero-based; saved metadata tracks
completed iterations N+1 for correct continuation.

Frozen sets are already generated at `logs/continuous_curve/20260910_c4_frozen_sets/`:
`development.json`, `holdout.json`, `manifest.json`. Neither set has been scored.
To regenerate reproducibly into a new directory:

```bash
./isaaclab.sh -p scripts/flapping_px4/evaluate_c4_training.py freeze --output /tmp/c4-new-sets
```

Explicit post-training evaluation (runs C4 and all five old suites):

```bash
./isaaclab.sh -p scripts/flapping_px4/evaluate_c4_training.py evaluate \
  --checkpoint <run>/model_200.pt \
  --curves logs/continuous_curve/20260910_c4_frozen_sets/development.json \
  --output <new-evaluation-directory>
```

Do not use holdout to tune or repeatedly select checkpoints. Existing original
fixed96 remains a diagnostic set; mild random96 passed zero-shot before training.
No formal training should be inferred from the presence of smoke checkpoints.
