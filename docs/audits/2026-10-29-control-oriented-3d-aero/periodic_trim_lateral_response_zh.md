# L-3D / I-3D 周期前飞与横侧向自由响应

本轮实际运行了 CPU-native measured multibody PhysX，没有训练策略、改变气动架构或修改飞行器参数。**两后端都找到了通过预先设定的八拍有限时域检查的近似周期前飞候选；自由响应差异有控制意义，但规定运动 `dMx/dβ` 反号并不推出固定的反向补偿策略。**

架构判断选择 **A，限定于本模型与本次有限时域近似周期判据**：保留两后端作为未来结构不确定性研究基础。没有证明精确周期轨道、无限时域开环稳定性或实机可迁移性。尤其 I 仍有小幅累积下沉；不能把“通过本次容差”写成严格水平配平。没有证据支持以“诱导无控制收益”为由选择 B，也不能依据早期失败候选宣称 C。

这补充并收窄[上一轮报告](report_zh.md)中“改变动作方向”的解释：之前的依据是规定运动力矩，本报告的依据是实际自由飞行及真实舵面动作。

## Q2：成对自由响应与真实舵面权限

每组包括无扰动、±0.5 m/s 侧风、+2 m/s 参考风、p/r 各 ±0.25 rad/s、方向/差动各 ±5°、侧风叠加各正负舵面，以及无扰动重复样本。另在完全共同初态使用 ±0.1 m/s 和 ±1° 缩幅。风为世界 +y，初始候选 β 因而为负；不能与旧报告正 β 数字直接同号比较。

各自最终候选先真实积分三拍，再施加扰动；L/I 起始时刻分别 .98750/.80208 s，保留启动高度变化。施加 p/r 扰动只在扰动时刻改变对应角速度，之后自由积分；不是持续施加理想力矩。尾舵经原四通道动作映射和实际关节执行器，命令在下一 60 Hz 时刻生效，延迟不超过一个动作步。

所有增量都减去**同后端、同初值、同控制历史**的无扰动轨迹。重复样本的最大速度误差约 1.2e-4 m/s、角速度约 2.2e-4 rad/s，显著低于主要响应。原始数据含三轴空速、候选 β、p/q/r、姿态、侧向位置/速度、高度、关节状态和风。

正差动对 p 的增益均为正，I 的 p 增益较大、对 r 的直接有限时域增益较小；方向舵也明显改变 p。两拍和一秒矩阵见 `final_analysis.json`，有显著时域依赖。仅按 p 补偿一拍侧风，两者均需负差动；只看 roll 偏差，两者则均需正差动。实际风+正/负舵配对验证了这一差异，角速度目标与角度目标不能混为一谈。

### 完全共同初态：是否真的反转方向？

采用 ±.1 m/s 风和 ±1° 舵的缩幅数据，第一拍的风增量 L/I 为：

- `(Δp, Δr)`：`(+.01681,−.01195)` / `(+.00517,−.03605)` rad/s。
- `(Δroll, Δyaw)`：`(−.111,−.542)` / `(−.304,−.761)`°。
- 差动到 p 的增益：`+.02126 / +.03321 (rad/s)/deg`。
- +风叠加 −1° 差动后的 Δp：`−.00455 / −.02807 rad/s`；叠加 +1° 后 `+.03808 / +.03837`。

**第一拍并未出现两模型需要相反差动方向的证据。** 两者对 p 都是负差动补偿，对 roll 都是正差动补偿。缩幅与原 .5 m/s / 5° 在第一拍保持该方向。

两拍共同瞬态的联合 p/r 补偿线性解确实可出现不同差动符号，但 L 矩阵接近退化、机体正进入大姿态演化；原幅值与缩幅增益幅值差异明显。这不能归纳为结构上稳健的“相反最优策略”。共同 L 的后期失控也不否定其**各自**候选可前飞。

### 有界联合补偿与剩余误差

用上述 E_h 解带真实舵面限位的两输入最小二乘。界限同时考虑既有方向/对称/差动配平，左右实际舵角不得超过 ±40.70865°。一拍消除 p/r 增量的预测增量命令为 L `(+5.023°,−2.274°)`、I `(+8.930°,−5.264°)`；一秒为 L `(−2.993°,+.946°)`、I `(+8.987°,−11.215°)`。这些方向是指定时域/工作点下的联合目标，不是静态 β 反馈律。

## 证据边界与后续架构判断

1. **数值实现：SUPPORTED。** 本轮真实积分、机械相位重复、实际尾舵和配对重复性检查通过；无新物理内核改动。新增三项分析测试通过。没有重复此前 32 项测试，也没有新做空间/时间全面收敛，微小差值不作结构定论。
2. **规定运动机制：保留前轮证据。** 原 `dMx/dβ` 反号来自规定运动；本轮证明自由体惯性、偏航/姿态耦合与执行器时间路径会改变它的控制含义。
3. **周期工作点：有限时域 SUPPORTED。** L 更接近水平重复，I 仍缓慢下沉；精确轨道和长期持续性 UNRESOLVED。前三拍是实际自由积分，不是冻结预热。
4. **控制相关性：SUPPORTED。** 差异延伸到实际 p/r、姿态、横移和有效舵面矩阵；但“一律相反补偿”不成立。两者在各自一秒工况有不同联合补偿方向，混有频率、相位、姿态、配平差异，不能全部归于诱导结构。
5. **实机真实性：UNRESOLVED。** 未测定柔性扭转/静态极线，诱导为准稳态直尾迹，附加质量仍为受限相对运动项；没有实机侧滑导数辨识、抗风能力或 sim-to-real 验证。未读封存 test、未重审 161 航次、未拟合日志整机力矩、未把 PX4 风估计当真风。

因此当前不需要以复杂化为目标升级完整 ULLT、动态失速或自由尾迹，也不支持用经验六轴导数补丁凑控制方向。A 的用途是保留可运行的物理结构对照，尚非正式 RL 性能排序或实机准入认证。后续是否进入 RL 由用户决定，本轮到此停止。
